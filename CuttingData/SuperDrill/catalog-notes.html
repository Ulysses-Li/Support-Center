Current selection and calculation rules

  • Match listed physical parts by nominal diameter, drilling depth T and rear shank diameter. Dmax does not extend the diameter range of a rotating drill.
  • Select the cutting row for the chosen 3D/4D body. L is the front dimension and L1 is rear shank length; neither replaces drilling depth T.
  • Inner and outer positions each use the same N9GX insert, grade NC2032. Feed f is in mm/rev and F=S×f; neither insert count nor indexable edges is a multiplier.
  • The catalog provides range endpoints only. Site arithmetic midpoints are adjustable starting values. An application-factor interval requires an explicit selection.
  • Without a material, only geometry can be viewed. Calculation and copying require a supported material. This series is not recommended for non-ferrous metals. No body recommendation is provided for heat-resistant or unknown materials without a listed pairing, and manual values cannot bypass this restriction. A labeled manual calculation remains available only for supported materials with incomplete parameters.
  • The catalog does not sufficiently define coolant pressure/flow, minimum clamping length, programmed tool-tip Z or bottom allowance. No automatic values or pass guarantees are generated.

Printed p136 is PDF page 1 and p141 is page 6. The data preserves original combined-document page numbers in original_pdf_page.

Manufacturer questions

Please provide official documents, version, date and page references for each body, material and application. Unconfirmed material suitability receives no recommendation; missing parameters for supported materials limit the affected functions.

Usable depth, tool-tip datum and hole-bottom profile

Provide the axial relationship of inner and outer edges, blind-hole bottom profiles, full-diameter cylindrical depth and through-hole overtravel drawings for each Super Drill diameter. Explain how catalog T relates to programmed tool-tip Z.

Question 02 · P2 · Catalog p136 ↗、Catalog p138 ↗

Minimum clamping length and coolant supply

Provide minimum coolant pressure, recommended flow, measurement location and minimum clamping length for each diameter and depth. L1 is a rear shank dimension, not the minimum clamping length.

Question 03 · P2 · Catalog p140 ↗、Catalog p141 ↗

Material boundaries and unlisted material data

How should exactly 0.3% carbon be classified? Does the p140 statement “up to HRC50” include HRC50 despite p141 specifying HRC<50? This series is not recommended for non-ferrous metals, and no heat-resistant material pairing is listed. Supply approval documents and cutting data for any formally changed scope.

Question 04 · P2 · Catalog p138 ↗、Catalog p139 ↗、Catalog p141 ↗

Lathe misalignment and radial adjustment

Explain the joint application of listed Radial Adjustment, Dmax and p141 center misalignment of +0.2/−0.5 mm, including permitted directions and usable-depth or clearance limits.

Question 05 · P2 · Catalog p141 ↗

Inch-feed formula and input units

The p141 inch box labels f as inch/rev but also divides feed by 25.4. Confirm the official formula and input units. Automatic output currently uses metric S and F only.

Question 06 · P2 · Catalog p140 ↗

Complete insert ordering format

The catalog lists the N9GX model and NC2032 grade separately. Provide the official combined ordering format if required; no suffix is invented.

Question 07 · P2 · Catalog p140 ↗、Catalog p141 ↗

Application factors and staged entry/exit

Provide the order, ratios and distances for combining application factors with lathe offset and staged entry or breakthrough. Confirm whether factors may be combined. A catalog interval is not silently replaced by its midpoint.
