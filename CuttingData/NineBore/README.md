# NineBore 正式選型工具

正式網址為 `/CuttingData/NineBore/index.html`，由 Cutting Data 與 Boring 的 NineBore 卡片進入。繁體中文使用 `?lang=zh-TW`。原廠補充資料頁為同目錄的 `manufacturer-questions.html`。

本頁依完工孔徑、深度、材料及刀柄／直柄介面篩選 99101、99121、99146、99151 刀桿；直柄另選後端柄徑。99121 與 99101 同時符合時，依每格 0.01／0.03 mm 的調整差異優先展示 99121。公差欄只描述完工孔徑上下限，不改寫客戶輸入的名目孔徑或切削計算。

## 資料與來源

- `data/` 保存產品、夾持介面及切削資料；`confirmed-specs.json` 保存已確認的柄徑選項、刀片配對、適材依據與切削條件共用確認。來源 PDF 放在 `sources/`，尺寸圖放在 `assets/line-drawings/`。
- 正式頁只讀本目錄的產品資源，並共用根目錄的 header、footer、材料色與背景。正式頁不依賴原型資料夾。
- 轉速為 `1000 × Vc / (π × 完工孔徑)`，每分鐘進給為 `S × f`。此處 f 是每轉進給。
- 自動建議須符合刀片實體、牌號、材料及加工條件。NC9036 僅列非鐵材料，不出現在不鏽鋼適材選項。
- 2026-11-18 使用者確認「一般切削與斷續切削一樣的參數」：現有 CCGT030102／NC30、CCGT040102／NC30 的碳鋼、合金鋼、不鏽鋼一般切削，沿用同材料 NC30 斷續切削列的 Vc、f 與 Ae。來源記為 `user_confirmation`，不改寫型錄原列，也不借用 NC2033 數值或新增外銷未販售的品項；其餘刀片配對及組裝限制仍分別核對。
- 2026-11-18 使用者確認 0602 尺寸沒有 NC30 刀片，記為已確認不可用；不再追問訂購碼，不新增 NC30 品項或自動以其他牌號替代。
- 2026-11-18 使用者確認 CCGH0602U 並非標準 ISO 形狀，主要用於鋁、銅及塑膠等非金屬材料的精細表面加工；「非金屬」用途已釐清。不要求標準 ISO／Re 資料，不推算 Re 或 Ra，不將 0.15 mm 特殊切削寬度當作 Re。塑膠等非金屬材料尚無切削參數，本次只補充用途說明；XP9001、NC9036、U-NC9036 的版本關係尚未確認。
- 2026-11-18 使用者確認 99121 後柄長度：Ø13、Ø16 均為 48 mm，Ø20 為 50 mm；適用型號與 L、L1 均依型錄，不因柄徑改變。下單方式亦已確認：Ø20 為一般預設，需要 Ø13／Ø16 由客戶額外告知；使用型錄型號加上柄徑需求的訂單註明方式，不自行建立新料號，也不將後柄長度當作最小有效夾持量。
- 2026-11-18 使用者確認 99101／99121 的型錄 L1 即可用搪孔深度，需求搪深小於或等於 L1 均符合；00-99121-05 的 L1＝15 mm 可加工深 15 mm。最小有效夾持量、可夾持區域及側固位置仍待補，不以後柄實體長度 48／50 mm 代替夾持量。需求深度不自動轉成機台 Z 程式。
- 2026-11-18 使用者確認 99151 刀桿 L 為刀桿總長，L1 為設計可加工深度。刀桿總長不當作整組刀具總長；轉接座插入量、定位固定、組裝伸出及 Ød1 缺漏仍待補，不因尺寸意義確認而推定這些數據。
- 2026-11-18 使用者確認中心出水需依實際需求另行洽詢訂製，不列為標準配備，也不推定每個型號皆可訂製；不再要求預先提供全型號的出水通路或配套總表。動平衡資料適用 99146，99101／99121 無動平衡；99151 尚未確認。G6.3／10,000 rpm 仍為平衡參考，不能作為全組共用最高轉速；各組最高可用轉速仍依實際總成資料另行提供。

- 2026-11-18 使用者確認 SB32 建議在可行情況下盡量夾入完整柄部，並非固定的硬性最小值，以實際有效夾持為準；保留外部機台刀柄夾持，不設定強制夾持長度。

- 2026-11-18 使用者釐清：刀具伸出長度可超過 L1，但須具有效夾持；加工深度仍小於或等於 L1。此原則不代表轉接座插入量、數值夾持長度或最高可用轉速已提供，也不改動既有加工深度界限。

## 原廠回覆頁

清單保留 7 個原始主題的錨點：原問題 01、02、04 已依 2026-11-18 使用者確認結案，分別記錄小刀片 NC30 共用參數、0602 無 NC30 的不可用狀態，以及 99121 後柄尺寸與下單柄徑註明方式。其餘 4 項待補中，原問題 03 已部分確認非標準 ISO 形狀及用途，改以「現行外銷配置＋具體材料與表面要求」分筆回覆選用條件，並列出仍需客戶補充的工件資料；原問題 05 已部分確認 99101／99121 的 L1 可用搪深（含深度等於 L1），僅保留最小有效夾持量、可夾持區域及側固位置待補；原問題 06 已部分確認 99151 刀桿 L／L1 的意義，僅保留轉接座插入量、定位固定、組裝伸出及 Ød1 缺漏待補；原問題 07 已部分確認中心出水需洽詢訂製、SB32 完整柄部夾入建議、伸出與加工深度區分及動平衡系列範圍，僅保留實際組裝最高可用轉速待補，特定配置的額外限制可選填。待補共 4 項，均為部分確認。來源中的牌號標示僅供核對，不預設三種可供應或可普遍替代的規格。清單附已知資料、問題、站內型錄頁碼與可編輯回覆欄。回覆不會送出或自動儲存，原廠可填寫後使用「列印／另存 PDF」保留。
