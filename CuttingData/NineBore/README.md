# NineBore 正式選型工具

正式網址為 `/CuttingData/NineBore/index.html`，由 Cutting Data 與 Boring 的 NineBore 卡片進入。繁體中文使用 `?lang=zh-TW`。原廠補充資料頁為同目錄的 `manufacturer-questions.html`。

本頁依完工孔徑、深度、材料及刀柄／直柄介面篩選 99101、99121、99146、99151 刀桿；直柄另選後端柄徑。99121 與 99101 同時符合時，依每格 0.01／0.03 mm 的調整差異優先展示 99121。公差欄只描述完工孔徑上下限，不改寫客戶輸入的名目孔徑或切削計算。

## 資料與來源

- `data/` 保存產品、夾持介面及切削資料；`confirmed-specs.json` 保存已確認的柄徑選項、刀片配對與適材依據。來源 PDF 放在 `sources/`，尺寸圖放在 `assets/line-drawings/`。
- 正式頁只讀本目錄的產品資源，並共用根目錄的 header、footer、材料色與背景。正式頁不依賴原型資料夾。
- 轉速為 `1000 × Vc / (π × 完工孔徑)`，每分鐘進給為 `S × f`。此處 f 是每轉進給。
- 自動建議須符合刀片實體、牌號、材料及加工條件。NC9036 僅列非鐵材料，不出現在不鏽鋼適材選項。
- 小刀片 NC30 的一般切削正式條件缺值時，另標明同材料斷續切削數據為試切參考，並連往原廠清單。這些數值不視為一般切削正式推薦，也不借用不存在的小刀片 NC2033。
- 直柄 L1 是前端頸長，不能直接視為組裝後保證加工深度；99151 的轉接座插入量與實際伸出仍須確認。需求深度不自動轉成機台 Z 程式。

## 原廠回覆頁

清單包含 7 個待確認主題，附已知資料、問題、站內型錄頁碼與可編輯回覆欄。回覆不會送出或自動儲存，原廠可填寫後使用「列印／另存 PDF」保留。
