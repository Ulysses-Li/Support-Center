# NineBore 正式選型工具

正式網址為 `/CuttingData/NineBore/index.html`，由 Cutting Data 與 Boring 的 NineBore 卡片進入。繁體中文使用 `?lang=zh-TW`。原廠補充資料頁為同目錄的 `manufacturer-questions.html`。

本頁依完工孔徑、深度、材料及刀柄／直柄介面篩選 99101、99121、99146、99151 刀桿；直柄另選後端柄徑。99121 與 99101 同時符合時，依每格 0.01／0.03 mm 的調整差異優先展示 99121。公差欄只描述完工孔徑上下限，不改寫客戶輸入的名目孔徑或切削計算。

## 資料與來源

- `data/` 保存產品、夾持介面及切削資料；`confirmed-specs.json` 保存已確認的柄徑選項、刀片配對、適材依據與切削條件共用確認。來源 PDF 放在 `sources/`，尺寸圖放在 `assets/line-drawings/`。
- 正式頁只讀本目錄的產品資源，並共用根目錄的 header、footer、材料色與背景。正式頁不依賴原型資料夾。
- 轉速為 `1000 × Vc / (π × 完工孔徑)`，每分鐘進給為 `S × f`。此處 f 是每轉進給。
- 自動建議須符合刀片實體、牌號、材料及加工條件。NC9036 僅列非鐵材料，不出現在不鏽鋼適材選項。
- 2026-11-18 使用者確認「一般切削與斷續切削一樣的參數」：現有 CCGT030102／NC30、CCGT040102／NC30 的碳鋼、合金鋼、不鏽鋼一般切削，沿用同材料 NC30 斷續切削列的 Vc、f 與 Ae。來源記為 `user_confirmation`，不改寫型錄原列，也不借用 NC2033 數值或新增外銷未販售的品項；其餘刀片配對及組裝限制仍分別核對。
- 2026-11-18 使用者確認 0602 尺寸沒有 NC30 刀片，記為已確認不可用；不再追問訂購碼，不新增 NC30 品項或自動以其他牌號替代。
- 直柄 L1 是前端頸長，不能直接視為組裝後保證加工深度；99151 的轉接座插入量與實際伸出仍須確認。需求深度不自動轉成機台 Z 程式。

## 原廠回覆頁

清單保留 7 個原始主題的錨點：原問題 01、02 已依 2026-11-18 使用者確認結案，分別列出小刀片 NC30 共用參數及 0602 無 NC30 的不可用狀態；其餘 5 項仍待確認，附已知資料、問題、站內型錄頁碼與可編輯回覆欄。回覆不會送出或自動儲存，原廠可填寫後使用「列印／另存 PDF」保留。
