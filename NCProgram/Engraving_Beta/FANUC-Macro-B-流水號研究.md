# FANUC Macro B 流水號雕刻研究

## 目標與目前狀態

評估讓 FANUC 控制器執行同一支程式，在每次完成一件後使用下一個流水號。現有樣板是在網頁先展開多個固定號碼，放在同一畫布並輸出普通座標刀路；**目前沒有輸出 Macro B，也沒有機台端逐件自動遞增**。

## 可行的實作方向

FANUC 將 Custom Macro / Custom Macro B 列為 CNC 選配功能，提供變數、數學運算、邏輯及程式流程控制；能否使用須依實際控制器及已啟用選項確認。（[FANUC CNC Options](https://www.fanucamerica.com/support/cnc/options)）

建議先限定一種已確認的控制器型號，再設計專用輸出：

1. 在機台確認可用的保留共用變數，記錄「下一件」的號碼，並檢查初始值及允許範圍。
2. 依位數拆出每一位數字，包括需要顯示的前導零。
3. 使用所選單線字型的 0–9 筆畫，為每個位置選擇對應字形刀路，套用字高、字距與雕刻座標。固定前綴或後綴可以另行輸出固定路徑。
4. 只有在機台確認雕刻完成後，才依遞增量更新號碼。需要明確規劃中斷、重啟、重刻及人工確認的處理方式。

這是設計方向，具體巨集語法、字形子程式配置與同步方式需要按指定機台的手冊和機台製造商設定驗證。FANUC 30i/31i/32i Model A 手冊 B-63944EN/03 的 II-556 頁說明巨集運算可能在預讀期間處理；不能只憑程式中的行順序認定雕刻已實際完成。（[FANUC 手冊](https://irp-cdn.multiscreensite.com/23c016fc/files/uploaded/FANUC-30i-63944EN_03-ProgManual.pdf)）

## 需要確認的機台差異

- **選配與語法**：控制器型號、版本、Macro B 選項、程式與子程式容量、可用的子程式號碼。
- **變數保留與占用**：例如 FANUC 30i/31i/32i Model A 使用手冊 B-63944EN/03 說明共用變數及擴充選項；不同機型與選配的範圍可能不同。必須確認斷電保留、變數是否已被機台、探針、夾具或其他程式使用，不能直接假設特定編號可覆寫。（[FANUC B-63944EN/03 手冊](https://irp-cdn.multiscreensite.com/23c016fc/files/uploaded/FANUC-30i-63944EN_03-ProgManual.pdf)）
- **編號範圍與精度**：依控制器數值表示及實測結果限定位數，不直接沿用網頁端的 16 位數上限。要定義溢位、最大號碼與前導零規則。
- **加工與復歸**：確認座標系、刀長、深度、進給、主軸、抬刀、進退刀與中斷復歸。雕刻與計數更新間若停機或斷電，需由操作流程決定重刻或前進，不能保證單靠計數器避免重號或漏號。
- **驗證**：先用對應控制器的模擬器／離線環境驗證位數進位、字形選擇、補零、上限及中斷情境，再依機台程序進行空跑和試切。

## 建議產品介面

保留目前「同一工件排多個號碼」功能；另外規劃「每件自動遞增（FANUC Macro B）」模式，讓使用者設定起號、最大號、位數、遞增量、字型及位置，並選擇經確認的控制器設定檔與專用變數。輸出前顯示目前號碼、下一號及中斷後處理提示。網頁預覽應展開指定測試號碼的筆畫，不能把一般 G-code 檢視器支援固定刀路視為已支援 Macro B 執行。
