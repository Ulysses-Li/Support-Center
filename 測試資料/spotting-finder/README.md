# Spotting 三條件選型樣板

本機檢視 `/測試資料/spotting-finder/index.html`。新增設計先在此評估，未發布、未套用正式 Spotting 版面。

- 材料、夾角、工件表面 Spotting 孔徑三條件在同一筆候選上比對；空白代表不限。無匹配保留條件，不靜默改角度或孔徑。
- 零結果會區分孔徑過大、過小、落在範圍缺口／無效切削邊界，以及材料／角度沒有對應組合。上限與可用區間只由目前材料＋角度的候選計算；可單獨清除不符條件，保留其他選擇。
- ACE 與 NC 直接引用正式產品資料；ACE 同時檢查 Dmax／Tmax 與尖端修正，NC 使用同組刀片／刀柄規格，不把名義尖點深度當成實體刀尖。
- Micro 暫讀研究分頁的 `../micro-spot-plan/filter-contract.json`，以印刷 p24–25 的材料／角度／Wmin–Wmax 名義範圍作條件式候選；鋼類硬度和牌號仍需核對。Micro 按鈕前往目錄研究頁，尚不提供虛構的 Z 或切削計算。
- 確認版面後，Micro 研究資料須整理進正式產品資料，再套用正式篩選器；正式頁不得依賴測試資料。
- 桌面三欄產品卡片，手機共用結構以手風琴呈現、預設收合且單開；原生鍵盤操作與 ARIA 狀態同步。
- ACE／NC 計算器入口帶入材料、角度、刀片和孔徑；既有正式 Spotting／產品總覽卡片也接到兩個計算器。

驗證：`node --test 測試資料/spotting-finder/tests/selector.test.js`。瀏覽器需檢查條件連動、零結果、計算器回填、手機手風琴和資源路徑。
