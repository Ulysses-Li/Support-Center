## 後續先向客戶取得

加工目標／工法、材料牌號與硬度、刀徑與刀尖 R、夾持介面與伸出需求、每刀切深 Ap／切寬 Ae，以及機台轉速與進給限制。已有刀具時先取得完整刀體、刀片料號及牌號。

## 必須保留的資料邊界

1. A Ø16 可對應 A06／Z3 或 A10／Z2，必須依完整型號選切削表。C 的相同 Type 也可能有不同料號與長度，不能合併。
2. A06 有 NC2032 實體刀片，但對應切削表未列該牌號的數值；C04 沒有淬硬鋼列所需的 NC2032 實體刀片。兩者都不能拿別組條件代填。
3. A 切削表兩幅工法圖的 Ap 各自保存，第二圖另有 Ae；官方圖名待確認。開槽進給減少30%的註記只套用 A。
4. C 要求 Ae < 2.5 mm；淬硬鋼列限定 HRC < 52，且只有 NC2032。
5. p164 延長桿不在這份六頁 PDF；接頭配對、Screw-Fit 鎖付扭力與實際組裝伸出仍需補充。0.6／0.9 Nm 是刀片螺絲扭力。
6. 表面品質比較圖的 A9MT1035／NC2033 與產品表 NC2032 不一致；量測指標與完整試切條件未明列，不能據此增加販售品項或保證表面品質。

來源 PDF 已與使用者提供檔案比對 SHA-256 一致，所有表列數據保留來源頁碼與原始精度。後續需重建閱讀頁時執行 `verification/review-and-report.py`；舊 `build-data.cjs` 保存首次整理流程，執行會重建初版資料與註記，勿用來覆寫本次複核中繼資料。
