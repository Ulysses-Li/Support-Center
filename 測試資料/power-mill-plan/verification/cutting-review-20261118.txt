一、核對結論
1. cutting-data.json 共18材質列：A 6.5mm 7列、A 10mm 7列、C 4列。ISO材料、示例牌號、Vc、fz、Ap/Ae及推薦牌號與可見來源一致，未發現轉錄錯誤。
2. A10 N材質的NC9031並非沒有實體刀片：p144列有A9GT103505H / NC9031 / Re0.5 / L10。可建立帶來源的候選鏈，但不能憑資料自動決定唯一刀把及唯一加工設定。
3. p145粗糙度圖說為A9MT1035 NC2033，而p144該刀片產品表及p145 A10鋼材切削表使用NC2032。這是來源內部矛盾，既有JSON有保留，不應將圖說牌號當成可售組合。
4. C切削表是系列層級牌號建議，不能略過刀片尺寸。H材料只列NC2032，而p147唯一實體NC2032是C9MT05T110H-NC2032（尺寸5、Re1.0）；C04沒有NC2032，不能建C04對H材料的推薦鏈。

四、p145全頁註記及粗糙度圖
1. 原文：Reduce the feed rate 30% from the below table for slotting operation.
   指定槽銑時將表列進給降低30%，剩餘倍率0.70；不是降到30%，也不是將Vc降低30%。註記在兩個A表上方，套用兩表有來源依據。原文用feed rate，表欄為fz；若未來計算fz或機台進給，應保留進給基準與運算條件，避免混用單位。未見可將本註記擴張套用到C表的依據。
2. 原文：Ramping angle should be under α°. (Please refer to holder specifications)
   是小於所選刀把的α，不是系列共用固定角度。p143兩種刀把表皆有α欄，必須按實體刀把列關聯。既有JSON採operator < 正確。
3. 粗糙度圖標示Competitor B 32µm、Competitor A 20.2µm、Nine9 14.5µm，Nine9圖說A9MT1035 NC2033。右側高度標0、7、14、21、28mm。
4. 圖未列Ra/Rz指標，也未列足以重現的完整加工工況；只能保留原標值與比較圖說，不能新增Ra/Rz名稱、通用改善百分比或保證值。
5. 牌號矛盾：p144尺寸10產品表A9MT1035只有NC2032；p145圖說卻為NC2033。p144尺寸06有NC2033，不能據此移植出A9MT1035-NC2033商品。

六、實體刀片與推薦鏈的可用程度
可建立「材質表列 -> 系列與刀片尺寸 -> 表列推薦牌號 -> 該尺寸實體刀片候選 -> 相容刀把候選」的有條件資料關聯，不能直接把牌號名視為商品，也不能只按刀徑選A6.5或A10。

A6.5 / p144、145：
- P/M/K表列NC5072可對應A9MT060205（Re0.5）。
- P/M/K表列NC2033可對應A9GT060201H、A9GT060202H、A9GT060205H、A9GT060210H（Re依序0.1、0.2、0.5、1.0）。
- N表列NC9031可對應A9GT060201H、A9GT060202H、A9GT060205H（Re依序0.1、0.2、0.5）。
- U型NC2032有實體刀片，p144文字也寫適用多種材質，但p145此尺寸切削表未列其牌號。不能無註記替代成NC5072/NC2033的同一套推薦切削規則。

A10 / p144、145：
- P/M/K表列NC2032可對應A9MT1035（Re0.4）。
- N表列NC9031可對應A9GT103505H（Re0.5）；確有實體產品。
- p145 N列不能誤配到A9MT1035，該列應配NC9031候選。
- p143存在同為D16但用06與10刀片的刀把，需按insert type/size連接，不能由D16直接決定使用哪張切削表。

C / p147：
- NC30候選：C9MT040105-NC30（L4/Re0.5）、C9MT040110-NC30（L4/Re1.0）、C9MT05T105-NC30（L5/Re0.5）。
- NC2032候選：C9MT05T110H-NC2032（L5/Re1.0）。
- P/M列不能因此產生不存在的C04 NC2032或C05 Re0.5 NC2032。
- H列只能得到尺寸5/Re1.0的NC2032候選；對尺寸4刀把應標示本六頁沒有對應推薦刀片，不借用NC30、A系列或經驗值補齊。

尚需保留的缺口：
1. A兩張工法圖的正式文字名稱未提供。
2. 粗糙度圖說牌號矛盾與測試條件缺漏。
3. 多刀把、多鼻R候選尚需使用者加工條件才能收斂；來源沒有唯一最佳商品或自動排序規則。
4. Ae/Ap等表列值未標成min/max，應保留原值與工法欄位，不自行解釋成所有條件下的最大允許切深。
5. 若後續要輸出機台轉速或每分鐘進給，還須選定刀徑、Z及範圍內的Vc/fz；本來源只提供範圍，沒有選點規則。
