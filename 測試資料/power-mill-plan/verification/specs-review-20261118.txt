結論
1. 沒有發現可確認的料號、Type、尺寸、Z、α、Ap、牌號或螺絲扭力轉錄錯誤。既有 JSON 的這些欄位與頁面可見表格相符。
2. 46 筆刀體是 46 個不同完整料號：A 23（圓柄11、Screw-Fit 12）；C 23（圓柄4、Screw-Fit 19）。這裡的 46 是刀體產品列數，不是以直徑去重後的數量。
3. A 有10種刀片基本料號、13種料號×牌號組合；C 有4種刀片料號、4種牌號組合。總計14種基本料號、17種牌號組合。
4. C Screw-Fit 有8組完全相同的 Type、不同 00-99802／00-99805 完整料號與不同 L；不能用 Type 當唯一鍵，也不能依 Type 去重。
5. A06／A10、C04／C05 的刀片群組有表格依據；不能因外觀、螺絲相同、直徑相同或尺寸代碼相近，就推定 A 與 C 刀片互換。

p144 重要語意
- 06與10是 Insert Size 分組文字，不能一律直接當作刀片實際 L；06 的 L 是6.5。
- A表把基本 Parts No. 和牌號分列；JSON 沒有自行拼成官方完整SKU，這個處理適當。
- H 型並不是每個 Re 都同時有 NC2033 與 NC9031：Re=1.0 的 A9GT060210H 僅列 NC2033。
- NC5072 的 ISO 等級為 P40；不要把 A 系列所有刀片都合併成 K20F。
- NC9031 的鍍層在表中是 TiN；其他所列牌號的來源呈現 TiAlN／TiAIN 易混字形。既有 JSON 對不一致字形保留原文字層且未正規化，可保留為待確認資料，不能因此宣稱已查證化學名稱。
- 刀片 L 與刀體 L 是不同實體尺寸；刀片 S、Re 與刀體 d1、L1 也不能跨表共用同一欄。

p147 可確認的規則
- C04 有兩個 Re，但這兩列都是 NC30／K10F；此表沒有 C04／NC2032列。
- C05 的 Re=0.5 列為 NC30／K10F；Re=1.0 的 H 列為 NC2032／K20F，不能把 Re 與牌號當作任意可交叉組合的選項。
- C04與A06雖使用同一螺絲 NS-18037、0.6Nm、NK-T6，也不能以此推定刀片互換。
- C05與C04都0.6Nm、都NK-T6，但螺絲料號不同；不可只依扭力或工具去重配件。
- p147刀片表沒有W或Ap欄。頁首示意的7°、15°是雙後角圖，不能放入刀體坡銑角α欄；Re1.0是示意圖標示，不能覆蓋全部刀片Re。

尚未明示／不應擴張的配對
1. p143與p146指向p164的延長桿：本六頁未提供延長桿料號、長度、接頭公差或逐支刀頭配對，不能只按M值臆造完整裝配。
