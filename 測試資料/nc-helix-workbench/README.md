# NC Helix Drill 單孔設定樣板

本機預覽：`http://127.0.0.1:5500/測試資料/nc-helix-workbench/index.html`。本設計已套用至正式 `CuttingData/NCHelixDrill/`；本資料夾只保留 HTML 供比較。下列程式、資料、來源及測試路徑均以正式資料夾為準，完整維護說明見該資料夾 README。

此版本提供「依孔需求選刀」及「我已有刀具」入口，搭配材料、冷卻、功率與可調整的切削條件，計算轉速／工作台進給、刀具中心軌道半徑、刀尖目標 Z、整圈數及實際每圈下降量。桌面共用雙欄工作表；手機改單欄並提供浮動摘要與結果跳轉。

## 資料與計算

- `data.js` 是本樣板的唯一產品資料：99321／99323 五尺寸、十二種原表材料；每列保留刀具尺寸對應的 Vc、fz、Pitch、grade 及來源圖。
- `sources/` 保存官方原表圖片與來源紀錄，客戶來源按鈕指向本機副本。官方圖片未印版次，本次核對日期為 2026-11-02。
- 原表孔徑直接使用表列 fz／Pitch；介於相鄰兩個原表孔徑時，樣板以線性估算提供起始值，並在畫面、來源說明與複製摘要標記估算範圍。此方法為樣板的輔助估算，需依實際加工確認；不代表原廠已核准的插值規則。
- 估算僅限同一刀具及材料、兩端均有有效資料的相鄰節點內，不外推、不跨越缺值節點。超出刀具範圍仍不提供有效結果。
- 例如 012-1525／碳鋼 0.25%C／Ø18：由 Ø15 與 Ø20 線性估算 fz = 0.053 mm/tooth，低功率 P = 1.38 mm/orbit；實際 P 仍由整圈分配計算。
- 原表列值已保留 012 系列 Vc 的 120／200、020 特殊 Vc、Al 345、Ni 28 及 025 不同材料的 fz 差異，不載入舊 NCProgram 的條件資料。
- 有效刀徑、孔徑範圍及型錄深度參照官方直柄／螺紋刀頭規格。螺紋刀頭仍須確認接桿伸出與干涉。
- 刀片最大 Pitch（3／4.5／6／7.5／9 mm）與刀具 20° 斜坡角分別驗證。
- `core.js` 以 `ceil(L/P)` 取得整圈數，再以 `L/圈數` 分配實際 P；摘要與複製內容同步顯示設定值及實際值。
- 轉速先四捨五入到整數，再以 `F = n × fz × z` 計算進給。作用齒數 2 是可調整初值，使用者須確認實際組裝。
- `diagrams.js` 俯視保留 D／Dc 比例；側視呈現螺旋中心運動與刀尖位置，不模擬刀片細節、孔底形狀或刀桿干涉。超過 20 圈使用代表性線圈並保留實際圈數標示。

## 互動與邊界

改變孔徑、材料、刀具、冷卻或功率會重新載入該組型錄初值；深度改變保留手動切削值。直徑／深度／Pitch 以 0.1 增減，fz 以 0.01 增減並保留手動輸入的更細精度。滾輪僅在欄位聚焦時調值。

俯視刀具中心沿逆時針（CCW）方向公轉，播放與手動進度使用相同方向。動畫須按下 Play 才播放；背景分頁、改變條件及減少動畫偏好會停止播放。減少動畫模式以離散步進呈現。

此一般單孔設計已接上正式 Cutting Data 入口。未提供階梯孔、預孔擴孔、底部精加工或控制器 NC 輸出。Open NC Program 僅開啟既有頁面，先以 Copy setup 傳遞摘要；不聲稱已自動帶入參數。既有正式 NC Helix 的切削表與刀路邏輯未在本次更動。
