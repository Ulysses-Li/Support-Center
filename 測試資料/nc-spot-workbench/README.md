# NC Spot Drill 本機互動樣板

本樣板參考正式 ACE 計算器的工作流程與技術圖面，使用 NC Spot Drill 自己的資料和模型。未修改正式 Cutting Data 入口，尚未發布。

本機網址：`http://127.0.0.1:5500/測試資料/nc-spot-workbench/index.html`

## 全品項範圍

- 直接以角度與型錄刀片族型號選型，再選完整牌號及相容刀柄。保留 nc06／nc08／nc10／nc14／v09／v13 等舊網址 ID。
- 普通型共 17 組裝配、48 個刀片組裝選項、36 個刀柄選項；同一刀片裝在不同角度刀柄時保留獨立的 Dmin／Dmax／Tmax。
- 包含 60° P60／V9MT、82° V082、90° N9MT05T1／0602／0802／11T3／1704／220408／2506、100°／120°／142° CT2T，以及 V142 兩種尺寸。
- 11 款 WSP 刀片另分為 3 個系列、6 支相容刀柄，採專用材質表和雙角度圖。
- 操作清單依已核對的產品用途篩選；P60 與 V142 不開放未列出的輪廓倒角模式。
- 料號查找支援完整刀片、刀柄、型錄 Code 及 14 個單套／入門包映射。共用刀柄或刀片有多個角度時，使用者必須明確選擇裝配。
- P60 規格依印刷 p.30，Dmax 5、Tmax 3，搭配 00-99616-14-12 或 00-99616-14。與 90° CT 共用刀柄，不能只由刀柄簡稱判斷角度。
- 使用者確認 P60 由 N9MT11T3CT 改製；對 P60 用途與 CT-NC40 材料矩陣的交集（一般碳鋼、低合金鋼、鑄鐵），自動帶入 p53 的 Vc／f 中間值，畫面與複製內容明示「CT 參考起始值」。高合金鋼缺少 CT-NC40 對應標示，保留手動輸入；不宣稱 P60 原廠專屬切削表。
- 型號、牌號與材料保持可見，不因目前材質缺乏配對資料而藏掉產品或靜默換材；未確認搭配提示原因並阻止複製加工條件。
- 獨立抄錄 small／standard／large 切削表，依操作帶入型錄中間值，作為網站預設起點。
- `S = 1000 Vc / (π Dmax cut)`；倒角以切削帶上緣最大直徑計算轉速。
- `F = S f`，單位為每轉進給 mm/rev。可轉用刃數不乘入公式。
- D／C／W 滾輪與方向鍵增量 0.1 mm；f 增量 0.01 mm/rev，保留手動輸入的較細精度。
- 切換倒角直徑上緣／中央／下緣時換算 D，保留同一切削帶及 R／Z。
- 同頁動態 SVG、複製條件、資料來源、手機結果列與共用導覽。
- PDF 原檔位於 `sources/`，顧客連結使用站內檔案。

## 幾何與對刀基準

型錄印刷 p.52 明示刀片不在刀柄中心，NC40／NC60 與其他牌號有不同實際剖面，因此沒有沿用 ACE 的 ℓ、Cmax 或 Tmax。

- 預設只呈現直線錐面名義幾何，Z 以理論尖點為基準，圖面使用虛線。
- 實測模式輸入同一刀柄／刀片／刀長設定下的已知直徑 Dref 與正深度 tref。
- `q = cot(α/2)`；`Δz = Dref q/2 − tref`；`Z = −(Dupper q/2 − Δz)`。
- 這是固定名義角度下的局部校正，不是實際旋轉曲面、刀柄干涉或進退刀驗證。
- Dref、tref 必須符合所選刀片 Dmin／Dmax／Tmax。CT 系列 NC40／NC60 的參考與目標檢查型錄所示 1 mm 最小深度；P60 未繼承 CT 的最低深度、牌號矩陣或 HRC 數值限制。
- 未知實際刀尖修正時，不將名義理論尖點深度直接與實際 Tmax 比較；實測模式才檢查校正後深度。
- 換刀柄或刀片時自動清除舊的實測參考。更改材料而保持同一組裝時可保留參考。
- 局部倒角以原始輪廓為 XY 基準，`R = D/2 − k W`、`H = W cot(α/2)`；k 為上緣 1／中央 0.5／下緣 0。只有 90° 刀片的等邊倒角稱 C，其他角度分開顯示 W／H。完整補正只套用一次，G41／G42 由走向及材料側決定，R 不是 CAM 磨耗補正。
- 90° 倒角檢查 1 mm 名義或實測校正後的軸向尖端間距。其他角度檢查切削帶的 Dmin 與正深度，並提示實體尖端避讓另查；p.52 的 1 mm 圖標明針對 90°，不能直接宣稱各角度已驗證。
- 共用 CT2T 刀片可搭 90°／100°／120°／142°。網址還原以完整裝配為準；只有共用刀片料號且無角度的深連結會要求選組合，不顯示可用結果。

## WSP 獨立公式

- 印刷 p.42 的 11 款 Metric／UNC 刀片各自有 D1、P、Dmax、Tmax。
- `Lreq = Dreq × 0.5 − P`，`Z = −Lreq`，不套普通錐尖校正或輪廓 R。
- `Dreq ≥ D1` 且同時檢查 Dmax、Tmax；型錄數值取整可能讓有效 Dreq 上限略低於名義 Dmax，不能直接截短深度。
- 「牙徑 +5%」採 p.43 的 Dreq = 名目牙徑 ×1.05 範例，不代表 C 寬度為牙徑5%。
- 專用 WSP Vc／f 以碳鋼、合金鋼、不鏽鋼、鑄鐵、HRC<50硬化鋼分組。未列出的材質不回填普通 CT 表。

## 來源版本

- 使用者提供的 19 頁分冊：2025–2026 ENG，印刷 pp.28–43、52–54。
- 官方舊型錄：站內 `NC-Spot-Drill-Legacy.pdf` 第13頁／印刷1-13，補齊120°、CT2T-142°；現行官方頁的牌號新增另記錄，沒有冒稱出現在舊冊。
- 官網目前主型錄檔名仍含2025–2026，但實際封面是2026 EN.202608；其 p.15 Dmin整頁證據存為站內PNG，與使用者分冊分開。
- P60及120°／CT2T-142°的 Dmin 另由官方總覽核對。P60 Dmax仍採使用者單件表5mm，100° Tmax仍採6.2mm，差異寫於來源紀錄。
- 規格來源與切削表來源分別保存；Legacy規格不能誤跳到同一PDF的第18頁冒充新分冊切削表。
