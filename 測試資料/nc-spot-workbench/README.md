# NC Spot Drill 本機互動樣板

本樣板參考正式 ACE 計算器的工作流程與技術圖面，使用 NC Spot Drill 自己的資料和模型。未修改正式 Cutting Data 入口，尚未發布。

本機網址：`http://127.0.0.1:5500/測試資料/nc-spot-workbench/index.html`

## 第一版範圍

- 直接以角度與型錄刀片族型號選型，再選完整牌號及相容刀柄。保留 nc06／nc08／nc10／nc14／v09／v13 等舊網址 ID。
- N9MT05T1CT、N9MT0602CT、N9MT0802、N9MT11T3CT／CT2T：90° 點鑽與局部直邊倒角。
- N9MT11T3P60、V9MT0802CT、V9MT12T3CT：60° 點鑽。
- P60 規格依印刷 p.30，Dmax 5、Tmax 3，搭配 00-99616-14-12 或 00-99616-14。與 90° CT 共用刀柄，不能只由刀柄簡稱判斷角度。
- P60 不在已核對 CT 切削表內，Vc／f 預設留空，由使用者輸入已建立的條件，複製內容標示手動來源。
- 型號、牌號與材料保持可見，不因目前材質缺乏配對資料而藏掉產品或靜默換材；未確認搭配提示原因並阻止複製加工條件。
- 獨立抄錄 small／standard／large 切削表，依操作帶入型錄中間值，作為網站預設起點。
- `S = 1000 Vc / (π Dmax cut)`；倒角以切削帶上緣最大直徑計算轉速。
- `F = S f`，單位為每轉進給 mm/rev。可轉用刃數不乘入公式。
- D／C 滾輪與方向鍵增量 0.1 mm；f 增量 0.01 mm/rev，保留手動輸入的較細精度。
- 切換倒角直徑上緣／中央／下緣時換算 D，保留同一切削帶及 R／Z。
- 同頁動態 SVG、複製條件、資料來源、手機結果列與共用導覽。
- PDF 原檔位於 `sources/`，顧客連結使用站內檔案。

## 幾何與對刀基準

型錄印刷 p.52 明示刀片不在刀柄中心，NC40／NC60 與其他牌號有不同實際剖面，因此沒有沿用 ACE 的 ℓ、Cmax 或 Tmax。

- 預設只呈現直線錐面名義幾何，Z 以理論尖點為基準，圖面使用虛線。
- 實測模式輸入同一刀柄／刀片／刀長設定下的已知直徑 Dref 與正深度 tref。
- `q = cot(α/2)`；`Δz = Dref q/2 − tref`；`Z = −(Dupper q/2 − Δz)`。
- 這是固定名義角度下的局部校正，不是實際旋轉曲面、刀柄干涉或進退刀驗證。
- Dref、tref 必須符合所選刀片 Dmax／Tmax。CT 系列 NC40／NC60 的參考與目標檢查型錄所示 1 mm 最小深度；P60 未繼承 CT 的最低深度、牌號矩陣或 HRC 數值限制。
- 未知實際刀尖修正時，不將名義理論尖點深度直接與實際 Tmax 比較；實測模式才檢查校正後深度。
- 換刀柄或刀片時自動清除舊的實測參考。更改材料而保持同一組裝時可保留參考。
- 90° 倒角以原始輪廓為 XY 基準，`R = D/2 − k C`；k 為上緣 1／中央 0.5／下緣 0。完整補正只套用一次，G41／G42 由走向及材料側決定，R 不是 CAM 磨耗補正。
- 倒角採型錄至少 1 mm 軸向尖端避讓；未測量時只檢查名義間距並清楚標示基準。
