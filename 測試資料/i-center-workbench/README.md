# i-Center 中心孔互動樣板

本機路徑 `/測試資料/i-center-workbench/index.html`。本樣板尚未套用正式 Centering 頁，未發布。

- 唯一產品資料：`../i-center-plan/research-data.json`；站內 PDF 使用同研究資料夾的 14 頁本機複本，印刷 p54–67。
- DIN A／A+B／R 與 ANSI 分開選型。主刀片 51 款，依型錄 d1 精確配對；同孔徑不同 IC、固定牌號與同 IC 刀柄清楚分列。料號／訂購碼可直接查找。
- 7 種材料與 10 欄切削表依 `cutting_column_join` 連接。IC10／d1 1.50 及 ANSI 的欄位缺口保持手動，不借用相鄰孔徑資料。
- S 與 f 顯示原始範圍及 f 原序列。依使用者要求，`Use median recommendation` 帶入本站中位數推薦：S 採型錄範圍與機台上限交集的中點；f 採表列序列中位數（偶數筆取中間兩值平均）。此為可調整的本站起點，不稱原廠最佳值。可另外填機台最高轉速，不把 G6.3／10,000 rpm 平衡參考當上限。
- 主結果是初始 S 與 Vf=S×f，不乘兩個切削刃。A+B 分開列出到 L2 後 S×0.7、f 不變、Vf×0.7 的階段資訊。
- 圖面標出型錄尺寸，A 的 d3／L3不畫成 B 保護錐。R 是圓弧承靠面；圖為非比例概念圖，不重建未知輪廓。
- Z 僅由使用者手動正深度換算 `Z=-t`，假設實際刀尖對到工件表面 Z0；L1／L2／L3不自動當成所有孔形的加工終點。
- 預設顯示可修改的範例：A+B、d1 2.5、IC10、碳鋼 C<0.3%、S4800／f0.05、手動範例深度6。初始 Vf240；L2=5.53 後 S3360／Vf168。深度6是展示輸入，非型錄預設終點。
- 手機底部同步顯示初始 S／Vf／手動 Z，與完整結果共用計算。材料色標、鍵盤、錯誤狀態及複製皆支援無障礙；動態內容先跳脫。

驗證：`node --test 測試資料/i-center-workbench/tests/*.test.js`，另以瀏覽器檢查孔形／標準切換、同 IC 刀柄、切削缺值、分段、手機與本地來源。
