Vf = S × f
8,000 × 0.002 = 16 mm/min
40,000 × 0.020 = 800 mm/min（僅支援該 f 的材料／刀片組合）

可選換算：Vc = π × D × S ÷ 1,000
此為換算值，不能標成型錄推薦 Vc。改 D 不應自動重新計算 S。型錄沒有 Micro 的 Q 或多段切深。

04 / GEOMETRY AND DATUM

先清楚顯示幾何，對刀計算留待圖面核實

p25 的 Re 圓角位於底部短平段與斜刃交界。可規劃同尺度剖面圖，顯示孔口 D、Wmin、Wmax、Tmax、Re 與夾角；圖應標記名義示意。

研究近似 t ≈ (D − Wmin) / [2 tan(θ/2)] 忽略 Re，屬於研究者推導。120°／D = 2.53 時計得 t ≈ 0.70148 mm，略高表列 Tmax 0.7 mm；142°／D = 2.42 時計得 t ≈ 0.39942 mm，表列為 0.4 mm。因此不可用此近似反過來剔除型錄端點。

第一版顯示型錄尺寸與切削設定，不輸出 CNC Z、G 碼、尖端補正或啄鑽 Q。本來源尚未提供實際／理論尖點基準、刀長對刀方式、Re 精確補償、跳動允差或機台可用 Z。ACE 的 ℓ 與 NC 結構說明不適用於補足這些缺口。

05 / INTERACTION PLAN

預定操作流程

  1. 加工條件材料／必要細類與硬度 → 夾角 → 目標孔口 D；從 Spotting 帶入時保留有效條件。
  2. 選刀與安裝匹配刀片／牌號 → 訂購碼 → 相容刀柄。尺寸、材質、長度與 XL 限制同區顯示。
  3. 切削設定直接輸入 S、f，可選填機台最高轉速；型錄範圍一直可見。
  4. 即時結果S、Vf、完整刀片／刀柄、材料條件、幾何尺寸及來源。有效條件可複製；不含機台 Z。
  5. 幾何說明名義剖面與對刀資料缺口；日後取得 Micro 專屬圖面再評估計算。

桌面與手機配置

沿用 ACE 的條件／選刀／結果架構與 Bootstrap 5.3.3。桌面左 7/12 條件、右 5/12 結果，左下放幾何圖。手機使用同一份表單及資料，單欄排列、精簡 S／Vf 結果條；完整結果仍在正文。共用根目錄 Header、Footer、背景與圖示，不建立副本。

必須明確處理的狀態

待填條件、條件式匹配、有效、無匹配及無效輸入。不要暗改使用者 D／材料／角度；上游切換只保留仍有效選項。材料不支援的角度附原因；未知 URL 值顯示無法套用條件。無效時清除舊結果並停用有效推薦複製。

D／f 使用 step = any 接受細微手動值；調整按鈕可用 D 每次 0.001 mm、f 每次 0.001 mm/rev。觸控至少 44px，動態訊息搭配 ARIA，幾何圖附文字說明，支援減少動畫。第一版顯示建議範圍，不宣稱單一最佳預設值。
